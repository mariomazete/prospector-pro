Prospector WhatsApp Connector

This Chrome/Chromium extension lets Prospector AI reuse an existing WhatsApp Web tab instead of opening duplicates.

Install:
1. Unzip prospector-whatsapp-connector.zip.
2. Open chrome://extensions in Chrome, Edge, Brave, Arc, Opera, or another Chromium browser.
3. Enable Developer mode.
4. Click Load unpacked and select the unzipped folder.

After installation, refresh Prospector AI. The Send WhatsApp button will focus and reuse the WhatsApp Web tab whenever one is already open.
